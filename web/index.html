Google / Gmail : comment connecter ?
  1. Connecte-toi à ton compte Google dans Opera.
  2. Active la validation en deux étapes si ton compte le permet.
  3. Crée un mot de passe d’application nommé JobBot et colle-le dans le champ prévu.
  4. Clique sur Vérifier. Ce test ne t’envoie aucun email.

Si l’option n’existe pas pour ton compte, choisis le mode navigateur. Une connexion OAuth en un clic demanderait une application Google autorisée ; elle n’est pas simulée ici.

Yahoo : comment connecter ?
  1. Connecte-toi à Yahoo Mail dans Opera.
  2. Ouvre la sécurité du compte, puis la rubrique des connexions externes / mots de passe d’application.
  3. Si Yahoo l’autorise, crée un mot de passe pour JobBot et colle-le dans le champ prévu.
  4. Clique sur Vérifier.

Yahoo peut ne pas proposer cette option. Le mode navigateur reste disponible : JobBot prépare le dossier, et tu termines l’envoi dans Yahoo.

Autoriser la recherche automatique de contacts dans Opera

Opera protège par défaut les résultats des moteurs de recherche. Pour que JobBot puisse y rechercher les profils LinkedIn et les coordonnées publiées, ouvre les réglages du module puis active Autoriser l’accès aux résultats de recherche dans sa fiche.

Cette étape se fait une fois, dans le navigateur de JobBot. JobBot ne change pas ce réglage à ta place. Le module ne demande aucun accès à tes messages Gmail ou Yahoo.

C’EST PARTI

De l’offre à la candidature.

01

Trouve une annonce

Dans la fenêtre Opera JobBot, indique un métier et une ville. Clique sur « Chercher sur les 8 sites ». Les quatre onglets s’ouvrent ensemble et leurs cartes d’offres arrivent ici. Si un site demande une connexion, ouvre son onglet et connecte-toi toi-même.

02

Ajoute-la ici

Clique sur « Voir et préparer » pour lire l’annonce et vérifier le CV proposé. Le bouton « Postuler » envoie par email si l’annonce le permet et si la messagerie est connectée ; sinon il ouvre le formulaire employeur.

03

Prépare le message

Ouvre la fiche, vérifie le CV et crée un brouillon. Tu peux rédiger une lettre personnalisée avec les textes inclus, sans clé, la modifier et joindre son PDF à l’envoi.

04

Postule et suis la suite

Le bouton Contacts affiche les pistes pour l’entreprise. Le message est préparé dans JobBot. Copie-le et ouvre LinkedIn ; termine l’envoi là-bas puis confirme-le dans le suivi des contacts.

Ce que contient cette version

Tes CV, un parcours de configuration au premier démarrage, recherche simultanée Indeed France, France Travail, HelloWork, LinkedIn, Météojob, Adecco, Manpower et Randstad, contacts publics sourcés, import d’annonces publiques compatibles, brouillons modifiables, envoi par Yahoo ou Gmail dans Opera avec CV et lettre PDF, envoi direct facultatif avec CV, suivi, détection des réponses dans le même fil si la messagerie est connectée, rappels de relance et notifications Telegram.

Le module de la fenêtre Opera JobBot lit les cartes affichées par les huit sites et les regroupe ici. Jusqu’à 30 cartes sont lues par page ; tu peux afficher une page suivante puis la relire, dans la limite de 300 offres conservées par site et par recherche. Un accès refusé ou une connexion nécessaire apparaît pour le site concerné. La lecture LinkedIn après connexion reste à vérifier avec ton compte. Les formulaires simples reconnus peuvent être remplis puis envoyés avec tes informations enregistrées. Les questions spécifiques, consentements, connexions et formulaires externes restent à terminer sur le site. Les adresses de recruteurs doivent venir d’une source que tu peux vérifier. JobBot fonctionne pendant que sa fenêtre de lancement reste ouverte.

Tes informations sont enregistrées dans le dossier « donnees ». Sauvegarde ce dossier pour conserver ton suivi. Si tu changes de compte Windows, ressaisis tes clés.
