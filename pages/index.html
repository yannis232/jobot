Ce que fait cette version GitHub

✓Depuis MoneyScout

Importer et comparer tes CV, lire les flux publics compatibles, rédiger tes lettres, créer tes PDF et suivre tes candidatures.

↗Avec la plateforme concernée

Se connecter à Yahoo, Gmail ou LinkedIn et confirmer les envois. Un site GitHub ne peut pas piloter leurs formulaires ni joindre des fichiers par un simple lien.

Ton espace n’est pas synchronisé entre appareils. Effacer les données de ce site efface aussi le coffre local. Aucune clé d’IA ni aucun mot de passe de plateforme n’est demandé.

Ressources externes et plateformes non connectées

Les plateformes ci-dessous ne fournissent pas toutes leurs annonces à un site GitHub sans accès autorisé. Ces liens restent disponibles en complément. La recherche principale consulte automatiquement tous les catalogues compatibles ; ces plateformes ne sont pas présentées comme des sources intégrées.
